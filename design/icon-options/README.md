# ScreenMover 图标候选

![四组图标与小尺寸预览](options.png)

| 方案 | 中文名 | 侧重点 |
| --- | --- | --- |
| A | 双屏转移 | 直观表达多显示器间移动窗口 |
| B | 窗口飞跃 | 更轻快，强调拖放和跨屏 |
| C | 桌面收纳 | 强调窗口隐藏和桌面整理 |
| D | 流动之窗 | 抽象 S 形，更适合作为独立品牌标记 |

四组为原创 SVG 几何图形，采用 Windows 11 常见的圆角、渐变与层间阴影；不是微软商标或官方系统图标。各方案附透明 PNG。当前等待用户选择，尚未替换程序图标或提交商店素材。

正式定稿时会分别调整 16/24/32/48 像素识别度，而不是只把大图无限缩小，并导出 ICO 与 MSIX/Store 资源。

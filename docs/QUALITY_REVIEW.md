# 质量与安全检查

适用版本：**v0.2.0**。以下为源码与自动检查范围，不构成无漏洞或无泄漏保证。

## 检查覆盖

- 设置编辑器、保存事务、快捷键选择器与轻量截图进程分离；版本和架构配置集中。
- 截图帧/IPC 长度有界，进程与窗口身份结合 PID、启动时间和 HWND 核对。
- 预览缓存最多 64 个；淘汰时释放模型引用。内存日志最多 500 条，文件按 4 MiB 归档。
- 游标、事件钩子、定时器及拖拽预览按生命周期释放；原生监听失败可降级轮询。
- 更新使用 HTTPS、官方域名、架构/版本匹配、SHA-256、解压上限和逐文件回退。
- 自动回归覆盖几何、托盘定位、单实例、设置冲突与回退、缓存引用、日志、更新协议和下载取消。
- 实际更新助手在临时无界面程序副本上验证等待父进程、替换、备份与重启，不修改用户安装。

## 资源检查

截图组件的 2,000 次系统图标采样测试中，GDI 句柄保持 0→0；缓存弱引用回归确认淘汰对象可回收。此测试不等同于整个主界面的长期内存验收。

NuGet 已知漏洞扫描以检查时的依赖源为准，不覆盖未知漏洞、所有 OS/驱动问题或第三方窗口内部行为。收到安全报告后仍需复现与修复。

## 验证边界

Win10 实机、实体多屏/混合 DPI/热插拔及主界面长期资源趋势仍需扩大设备覆盖。更新摘要依赖 GitHub 发布渠道的可信度，不等于独立发布者签名；断电/强杀及新版运行期故障不保证自动回退。当前包未进行商业代码签名，未完成 Store/MSIX 认证。

# 开发路线

当前正式版为 **v0.2.0**，功能和使用方式见 [README](../README.md)。这里只维护后续计划，不记录逐轮开发过程。

| 优先级 | 方向 | 验收目标 |
| --- | --- | --- |
| P1 | 兼容与可靠性 | Win10 实机、混合 DPI、多屏热插拔、管理员窗口和长期资源趋势 |
| P1 | 无障碍与英语界面 | 完整键盘操作、读屏名称、界面本地化；英文 README 已提供 |
| P1 | 发行与授权 | 选择原创代码许可证，完成安装包/签名与 Store/MSIX 工作 |
| P2 | 窗口暂存区 | 按任务分组、复用已创建的桌面、清晰找回与操作回退 |
| P2 | 显示器识别与离屏找回 | 屏幕别名、显示身份、断屏后可控地找回窗口 |
| P2 | 演示时的预览隐私 | 可排除应用、关闭敏感缩略图；不承诺替代屏幕共享软件的安全控制 |
| P3 | 新架构 | 按 ARCHITECTURE.md 适配 x86/ARM64 后分别验收和发行 |

上面均为计划，不代表已经实现。方向依据见 [竞品与定位](COMPETITORS.md)。[Store 计划](STORE_PLAN.md) · [架构准备](ARCHITECTURE.md) · [测试清单](MANUAL_TEST.md)。

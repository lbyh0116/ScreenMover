# 隐私与本地数据

ScreenMover 在本机枚举窗口、移动窗口并采样截图。窗口与显示器截图不写入磁盘、不上传；关闭截图后清除对应预览引用。窗口缩略图最多保留 64 个，优先当前屏幕，超额使用图标。

用户目录下的 ScreenMover 数据包含设置、仍打开窗口的排序、隐藏找回记录与操作日志。隐藏记录和操作日志可能包含软件名称、窗口标题及本机几何信息，不应未经脱敏公开分享。设置中的“打开数据与完整操作记录”可查看这些文件。

操作记录界面仅载入最近 500 条；活动日志达到 4 MiB 后会归档到同一文件夹，历史不会因归档被删除。单条异常长记录会截断，避免异常窗口标题占用过多内存。

导出设置排除设备尺寸和隐藏记录；诊断 ZIP 使用字段白名单，不包含截图、窗口标题、显示器名称、用户路径或原始日志。快捷键偏好会包含在设置中。

不启用遥测或后台联网检查。用户点击“检查更新”时，应用访问 GitHub Releases API；点击“下载并安装”时，从 GitHub 及其官方资源域名下载发布包。请求包含应用版本的 User-Agent，GitHub 会收到网络请求的 IP 等常规连接信息，不发送窗口标题、截图、快捷键设置或操作日志。点击“版本与下载”“反馈问题”等链接会由默认浏览器访问 GitHub，并适用该网站的隐私政策。登录后启动默认关闭；启用时写入当前用户的 Windows 启动项。

下载包、待安装文件、更新计划、结果及旧程序备份存放在本地数据目录的 updates 文件夹，不包含窗口截图。成功安装后备份暂不自动清除，便于恢复；确认版本正常后可在退出软件时清理对应更新会话目录。更新结果可能包含安装路径，不应未经脱敏公开。

API 失败时，正式渠道可回退到同一项目的 releases/latest；包含预览版时使用公开 releases.atom。校验和来自该发布的附件，仍只连接 GitHub 官方域名。

# v0.2.0 手动验收清单

用于新设备和后续回归，不作为逐轮工作记录。请使用独立测试副本进行可能改变窗口位置或安装文件的测试。

| 场景 | 验收重点 |
| --- | --- |
| 主界面 | 相册网格随尺寸变化；空显示器没有旧卡片；窗口选择、多选、搜索与取消正确 |
| 预览 | 屏幕保持比例、窗口填充；最小化/受保护窗口回退；关闭截图后释放引用 |
| 拖拽 | 按压反馈、排序记忆、单层预览、操作遮罩与滚动虚线；取消后恢复 |
| 移动 | 普通/最小化/最大化、多选、负坐标、混合 DPI；撤销保留原状态 |
| 托盘 | 重复点击打开/收起、点击外部或 Esc 收起、各任务栏方向及高 DPI 定位 |
| 隐藏与找回 | 已适配系统上处理正确目标；保留恢复记录；未知构建明确禁用；不关闭应用 |
| 设置 | 快捷键预设/组合/清除、冲突回退、主题与自动保存、导入导出与启动项 |
| 更新 | 正式/预览渠道、断网/限流/取消、SHA-256 校验、可写目录与占用文件提示 |
| 实际升级 | 旧实例退出、原地安装与重启、设置和找回记录保留；先保留完整旧包 |
| 系统边界 | Win10 实机、管理员窗口、断屏/重连、睡眠唤醒和多种显卡 |
| 长期使用 | 反复打开面板/设置、切主题、窗口大量增减，观察内存与 GDI/USER 句柄趋势 |

自动检查：`build.ps1 -PureTest`；不操作用户窗口。更新替换失败的回退已用临时文件和无界面程序副本测试，不保证断电、强杀或新版运行期崩溃自动恢复。

安全边界与已知限制见 [兼容说明](COMPATIBILITY.md)、[更新说明](UPDATES.md) 和 [隐私说明](PRIVACY.md)。

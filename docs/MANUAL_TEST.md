# 2026-10-17 手动验收

从托盘退出旧版本，再运行 `dist\ScreenMover-preview-5\ScreenMover.exe`。本轮未使用 computer use、未启动图形界面检查；已完成构建、编译后的 XAML/PRI 检查与无界面的逻辑回归。

1. **统一选中**：主窗口的屏幕、相册卡片，以及快捷面板的窗口行，选中时都应出现主题色细边框和统一圆角。检查浅色/深色、Ctrl/Shift 多选及键盘选择，不应再叠加方形选中底色。
2. **取消选择**：在已选窗口后点击页面/列表的空白位置，应取消选中。点击操作按钮、搜索框、下拉框或屏幕，不应意外取消操作所需的窗口选择。
3. **拖拽实物反馈**：按住窗口卡片应缩小、变暗；开始拖动后，真实卡片/窗口行的图像跟随抓取点移动，原位置淡化。多选时应显示数量。松开、Esc、移出后取消或丢失捕获后，源卡片应恢复，不留下暗块或浮层。
4. **屏幕操作遮罩**：主界面和快捷面板中，拖到屏幕应显示半透明主题色遮罩与操作标签。主界面同屏为“已在此屏幕”，其他屏幕为移动，未启用屏幕不能接收；快捷面板同屏为“隐藏到新桌面”，其他屏幕为移动。移开应立即清除。请用可随时关闭的测试窗口检查隐藏与找回。
5. **快捷面板精简**：应为紧凑的两栏列表/屏幕预览、云母背景、系统圆角；没有外圈白边、常驻底栏或设置按钮。右上角打开主界面，已隐藏入口和退出仍在主界面/托盘菜单中。操作结果仅短暂显示。
6. **外部点击**：点击桌面、任务栏、其他软件或主窗口，应收起快捷面板；下拉框内部交互和拖拽不能提前关闭。连续点击托盘和按 Esc 应稳定开关。未启用 Windows 透明/动画效果时，系统会回退材质或停用自定义过渡。
7. **布局与尺寸**：主窗口无论横竖都保持相册网格，只改变列数。重启后尺寸、窗口排序应保留；矮窗口应保留可用列表区域。不同 DPI 双屏下检查实际位置和比例。
8. **说明入口**：主界面不再铺满常驻操作指南；在“设置 → 操作说明与快捷键”中可查到多选、拖放、快捷面板隐藏和找回规则。
9. **单实例**：再次运行同一个新版 exe，应唤醒现有主窗口，不新增托盘图标或另一个主窗口。测试截图辅助进程、已隐藏找回与管理员重启仍应可用。旧版没有单实例协议，首次更换版本前必须退出旧版。
10. **可选开机启动**：默认保持关闭。如需验证，请在设置中主动开启“登录 Windows 后启动到托盘”，自行注销/重启后应只出现托盘图标；关闭该设置应移除启动项。开发检查没有改写实际启动项。

无界面回归覆盖：移动/隐藏/同屏/未启用/混合来源的拖放决策、紧凑面板几何、多 DPI/负坐标/四边任务栏、旧配置兼容、排序持久化、单实例互斥与 IPC 通知、带空格路径的启动参数。它们不能替代以上实际交互检查。


## 本轮新增：快捷键与数据工具

11. 在设置的全局快捷键输入框录入组合，例如 Ctrl+Alt+Space，保存后切到其他软件，测试打开/收起快捷面板。默认为关闭；“清除快捷键”禁用；Delete 不清空。长按不应连续切换。F12、无 Ctrl/Alt/Win 的单键及明确系统保留组合应被拒绝。若被占用，保存应失败并保留旧绑定和旧设置。
12. 设置 → 设置备份与诊断：导出前会保存有效偏好；导入后自动保存生效。快捷键冲突或无效值不能覆盖上次有效设置。损坏、空、错误格式/版本、过大的 JSON 应显示错误，当前编辑区保持原状。尺寸、排序、启动项和隐藏记录不迁移。
13. 导出诊断 ZIP，人工查看仅包含 diagnostics.json 和 README.txt；JSON 中有版本、构建编号、系统、屏幕几何和设置，不得有窗口标题、截图、显示器名称、用户路径或原始日志。取消文件选择应无导出文件。文件选择在普通权限和管理员运行时均需实测。
14. 退出后快捷键应释放。新预览与旧版共享单实例标识，启动新版本前必须先从托盘退出旧实例，否则再次启动只会唤醒旧窗口。

## 0.2.0-preview.2：本次反馈重点

15. 快捷面板在 1～3 个窗口、单屏时应接近 350 × 258 DIP；窗口/屏幕增加后在接近 4:3 的范围内增长，较多内容滚动。软件名列不得随总宽度变成大块空框。切换来源屏幕或移走窗口后应重新计算尺寸。
16. 快捷列表只显示软件名：Word 不显示文档名；同软件多个窗口仍分别列出，悬停查看完整标题。拖拽使用真实窗口句柄，不能把同名软件的多个窗口错误合并。
17. 拖拽截图自身的圆角/选中边框可以保留；外面不能再出现第二层主题色大框或重复标题。
18. 检查快捷面板激活、失焦收起、再次打开、浅/深色主题切换后，外围白线是否消失。此项尚未人工验证；代码已处理 Windows 原生非客户区、边缘样式和 DWM 边框颜色。

## 0.2.0-preview.3：待人工验收

19. 在主屏打开窗口，启用一个空的扩展/虚拟显示器，来回切换屏幕：空屏计数与卡片均应为零；所有屏幕开关和搜索无结果也应清空旧卡片。最小化/最大化窗口仍按所属屏幕筛选。
20. 在系统浅色/深色以及软件强制浅色/深色之间切换并重启：标题栏、背景和文字一致，不应有白色标题条或黑字配深背景；拖动标题栏、双击最大化和系统窗口按钮正常。
21. 设置占满主窗口内容区，左上角返回或 Esc 返回主界面，有效变更自动保存；颜色和主题持久化。测试自定义亮色（如白色、黄色）、深色和跟随系统，选中边框、操作记录和投放反馈同步。
22. 主界面与快捷面板拖入屏幕卡片时，跟随预览收起，仅保留屏幕遮罩和白字；移出后预览恢复，释放/取消后遮罩消失。亮色主题色的遮罩也要可读。
23. 设置中导入/导出、快捷键冲突、非法数字、开机启动失败应正确提示并保留旧设置；重复进入设置不应重复触发保存。


## 0.2.0-preview.4：待人工验收

24. 横屏、竖屏、超宽屏预览保持相同高度，卡片宽度随比例变化；主界面横向滚动与快捷面板纵向滚动正常。截图开关、未启用屏幕和热插拔也不应破坏比例。
25. 软件缩略图填满预览区，允许裁切；不可截图的软件图标保持小尺寸。选中框变细，拖到屏幕后显示较淡的遮罩和较小白字，只有拖放目标出现滚动虚线。释放、取消、Esc 和失焦后恢复普通边框。关闭系统动画后虚线静止。
26. 连续点击同一托盘图标：打开→关闭→打开，不应关后立刻重开。测试慢点击、鼠标移出取消点击、键盘激活通知图标、点击外部后重新打开；四个任务栏方向和高 DPI 的滑入都应连贯，无先闪现内容。
27. 设置独立的隐藏快捷键，例如 Ctrl+Alt+H。切到普通软件、最大化软件或其模态窗口，按键后应隐藏当前软件窗口，主界面不应抢焦点；在「已隐藏」中可找回。桌面、任务栏与 ScreenMover 自身不应被隐藏；管理员窗口另行按权限验收。
28. 打开面板和隐藏窗口不能设置相同快捷键；第二个快捷键冲突或保存失败时，两者原有绑定都应保留。清除、导入/导出、重启和退出释放都需验证。
29. 跟随系统时比较 Windows 自身控件强调色，深色采用较浅色变体，浅色采用较深色变体。切换主题和系统强调色后同步；自定义色不随系统变化。


## 0.2.0-preview.5：待人工验收

30. C 图标应出现在新文件夹的 EXE、托盘和任务栏；先退出旧实例，再打开新版，避免测试到旧版。
31. 快捷键右侧箭头打开与输入栏等宽的列表；预设、自定义修饰键和主键均能选择，无需按键。原有按键录入仍可用，Delete/Backspace 不清空；清除按钮停用。快速组合后立即返回也要保存最终有效选择。
32. 设置页不再有底部两个按钮。修改主题、截图、数值和快捷键后自动保存；返回、关闭再进入、退出重启后值保留。冲突、非法数字和磁盘/启动项权限错误应清晰显示于页头，保留旧有效值。
33. Win10 22H2 x64：启动、浅/深色、亚克力或纯色回退、系统原生标题栏、预览、跨显示器移动、托盘开关、面板快捷键与退出。独立虚拟桌面隐藏和隐藏快捷键应不可用，当前屏幕投放不得创建失败隐藏记录。
34. Win11：保留云母和已适配构建上的隐藏/找回；其他构建也能使用基本功能，不能调用未知虚拟桌面接口。
35. 多次开关设置/快捷面板、切换主题、拖拽、关闭软件窗口与定时刷新，观察主进程内存及句柄的长期趋势；新截图组件测试不等同于主界面长期验收。超额窗口只缓存当前优先的 64 个截图，其余图标回退；切换来源后刷新优先级更新。
36. 操作记录展示最近 500 条；完整历史与归档可在数据文件夹找到。隐私/反馈入口、偏好导入导出和诊断包字段继续回归。
